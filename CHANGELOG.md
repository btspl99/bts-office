# Changelog

Release notes live in [`website/releases.json`](website/releases.json). That one file feeds the website, the in-app "What's new" note and the GitHub Release. This file summarises the same notes.

## 1.3.1 (2026-10-17)
- Hindi and Marathi keyboards: InScript (the standard Windows keyboard), Remington (GAIL) for Kruti Dev typists, and phonetic typing with suggestions as you type. An on-screen keyboard shows where every letter is.
- New File > Options page: spell-check languages, default save format, how often autosave runs, default font and paper size for new files, cm or inches, default typing language and keyboard.
- About is now its own page in the File menu.

## 1.3.0 (2026-10-17)
- PDF: fill in forms, add your signature and photo, merge, split, reorder and rotate pages, compress to under 200 KB for upload portals, turn photos into a PDF, convert PDF to Word, and make scanned pages searchable in English, Hindi and Marathi.
- Type in Hindi or Marathi with English letters (Ctrl+Alt+H / Ctrl+Alt+M), and convert old Kruti Dev and Shivaji text to Unicode and back, in every app.
- Voice typing in English and Hindi (Alt+Shift+D). Works offline after a one-time download.
- Slides: SmartArt diagrams, equations, export as an MP4 video with recorded narration, and save as .odp.
- Sheets: grade calculator, CGPA to percentage converter, project plan (Gantt) and timeline templates, and save as .ods.
- Docs: SmartArt diagrams, citation lookup by DOI or ISBN, and save as .odt.
- Autosave and recovery in Sheets and Slides, and spelling suggestions when you right-click a word.

## 1.2.0 (2026-10-15)
- 50 professional fonts built in, including Hindi and Marathi fonts and look-alikes for Calibri, Cambria, Arial and Times New Roman, with a searchable font picker.
- Docs: track changes, citations and bibliography (APA, MLA, IEEE, Harvard, Chicago), captions, mail merge for certificates and letters, 14 style sets, a Styles pane and an accessibility checker.
- Sheets: PivotTables, sparklines, Goal Seek, Flash Fill, sheet protection, threaded comments, 12 workbook themes, 28 table styles and 9 new chart types.
- Slides: presenter view, rehearse timings, Slide Master, reuse slides, comments, handouts PDF and 31 themes.
- Every app: search any command with Alt+Q, document properties, and version history that keeps a copy every time you save.

## 1.1.0 (2026-10-15)
- Automatic updates from office.btspl.tech: downloads in the background and installs when you close the app.
- Updates section in File > Options & about, with Check for updates and an on/off switch.
- The start screen shows your version and update status.

## 1.0.0 (2026-10-14)
- First release: BTS Docs, BTS Sheets, BTS Slides and BTS PDF.
- Opens and saves .docx, .xlsx and .pptx; PDF export from every app.
- Student templates, light and dark themes, recent files, drag-and-drop.
